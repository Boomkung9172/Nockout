# ระบบจองโต๊ะผับบาร์ เมืองสงขลา (Songkhla Pub & Bar Table Booking System)

ระบบเว็บแอปพลิเคชันจองโต๊ะผับและบาร์ในอำเภอเมืองสงขลา พัฒนาด้วย **PHP + MySQL** ในธีมระดับพรีเมียม **สีดำ-ทอง (Luxury Black & Gold)** รองรับการทำงานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

---

## 🌟 ฟีเจอร์หลักในระบบ (ตรงตามข้อกำหนด 12 ข้อ)

1. **PHP + MySQL**: พัฒนาด้วย Native PHP + PDO รองรับ Prepared Statements ปลอดภัยจาก SQL Injection
2. **ธีมดีไซน์ สีดำ-ทอง (Black & Gold)**: สไตล์เรียบหรู คลับกลางคืน แสงนีออนสีทองอร่าม พร้อม Glassmorphism
3. **ระบบผู้ใช้และการยืนยันตัวตน (Login & Register)**:
   - มีระบบสมัครสมาชิกและเข้าสู่ระบบ แยกสิทธิ์ผู้ใช้ทั่วไปและแอดมินชัดเจน
   - ปุ่ม Quick Login สำหรับทดสอบบัญชีแอดมินและผู้ใช้ด้วยการคลิกเพียงครั้งเดียว

5. **กรอบสี่เหลี่ยมเลือกร้านในเมืองสงขลา**:
   - **Nockout Pub & Music Bar** (ถ.ไทรบุรี อ.เมืองสงขลา)
   - **Fullmoon Club Songkhla** (เลียบหาดชลาทัศน์ อ.เมืองสงขลา)
6. **กฎการตัดสิทธิ์ 20.00 น. (Cutoff Rule)**:
   - จองโต๊ะและเดินทางมาเช็คอินได้ไม่เกิน **20.00 น.**
   - หากพ้นเวลา 20.00 น. แล้วลูกค้ายังไม่มาเช็คอิน ระบบจะตัดสถานะเป็น **"ไม่ได้มาตามเวลา (No-Show)"** และปล่อยโต๊ะให้ว่างโดยอัตโนมัติ
7. **นัดหมายเวลาล่วงหน้า & เลือกโปรเปิดโต๊ะ**:
   - เลือกระบุเวลาที่จะมาถึงร้านล่วงหน้าได้ (17:30 - 20:00 น.)
   - สามารถเลือกเซ็ตโปรโมชั่นเปิดโต๊ะพร้อมสั่งไว้ล่วงหน้าได้ทันที
8. **สไลด์โปรโมชั่นหน้าแรก พร้อมภาพ AI**:
   - **โปรเบียร์ช้าง**: เบียร์ช้าง 3 ขวด พร้อมน้ำแข็งถังใหญ่ เพียง **199 บาท**
   - **โปรแสงโสม**: แสงโสม 1 ลิตร พร้อมมิกเซอร์โค้กหรือสไปร์ท 4 ขวด + น้ำแข็งถังใหญ่ เพียง **599 บาท**
   - รูปภาพสร้างด้วย AI คุณภาพสูงสมจริงระดับ Ultra HD
9. **ระบบชำระเงิน PromptPay**:
   - แสดง QR Code พร้อมเพย์ตามยอดบิลจริง
   - ระบบอัปโหลดสลิปหลักฐานการโอนเงิน (Slip Upload) พร้อมพรีวิวรูปภาพ
10. **ระบบสะสมแต้ม (Loyalty Points)**:
    - ได้รับแต้มสะสมทุกการจองและสั่งโปรโมชั่น
    - สมาชิกใหม่รับทันที 50 แต้ม
    - มีระบบนำแต้มไปแลกรับของรางวัล (เช่น ฟรีถังน้ำแข็ง, มิกเซอร์ 4 ขวด, คูปองส่วนลด 150 บาท)
    - บันทึกประวัติแต้มเข้า-ออกอย่างละเอียด
11. **ระบบแสดงโต๊ะที่จองไว้ ในหน้าจองโต๊ะ (Visual Table Map)**:
    - ผังโต๊ะจำลองแบ่งตามโซน (VIP Lounge, หน้าเวที Stage, โซนในร้าน Indoor, ระเบียง Outdoor)
    - แสดงสถานะโต๊ะชัดเจน: **ว่าง (สีทอง)**, **จองแล้ว (สีแดง)**, **ปิดซ่อมบำรุง (สีเทา)**
12. **ระบบติดต่อแอดมิน (Contact Support)**:
    - ฟอร์มส่งข้อความติดต่อสอบถาม/แจ้งปัญหา
    - กล่องข้อความแสดงประวัติและการตอบกลับจากแอดมิน
    - ข้อมูลโทรศัพท์และ LINE ID ทางการของร้าน
13. **ระบบแอดมินแยกส่วน (Admin Dashboard)**:
    - แผงควบคุมภาพรวมยอดจองและรายได้
    - **ระบบแก้ไขการจัดโต๊ะให้ลูกค้า (Reassign Seating)** สลับโต๊ะหรือย้ายโซนให้ลูกค้าได้ทันที
    - ระบบตรวจสอบสลิปโอนเงิน และปุ่มเช็คอินลูกค้า
    - ระบบจัดการเพิ่ม/แก้ไขโปรโมชั่น

## 🚀 วิธีการติดตั้งและเริ่มต้นใช้งาน (Installation & Setup)

### วิธีที่ 1: ติดตั้งผ่าน XAMPP
1. นำโฟลเดอร์โปรเจกต์นี้ไปวางไว้ในโฟลเดอร์ `htdocs/` ของ XAMPP (เช่น `C:/xampp/htdocs/fervent-pasteur/`)
2. เปิด **XAMPP Control Panel** แล้วกด **Start** ที่โมดูล **Apache** และ **MySQL**
3. เปิดเว็บเบราว์เซอร์ไปที่:
   ```
   http://localhost/fervent-pasteur/setup.php
   ```
4. กดปุ่ม **"⚡ เริ่มต้นติดตั้งฐานข้อมูล (Click to Install)"**
   ระบบจะทำการสร้างฐานข้อมูล `pub_booking_db` ตารางข้อมูล และข้อมูลเริ่มต้นให้อัตโนมัติทันที
5. เข้าสู่ระบบด้วยบัญชีแอดมินหรือผู้ใช้ตามที่ระบุไว้

### วิธีที่ 2: รันผ่าน PHP Built-in Server
1. รันสคริปต์ setup ผ่าน CLI:
   ```bash
   php setup.php
   ```
2. รัน Local Server:
   ```bash
   php -S localhost:8000
   ```
3. เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
