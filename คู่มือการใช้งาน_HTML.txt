             (ระบบจองโต๊ะผับบาร์สงขลา - Black & Gold Edition)
====================================================================

📁 โฟลเดอร์นี้รวบรวมไฟล์ HTML ทั้งหมด สำหรับส่งให้อาจารย์ หรือเปิดพรีวิว
โดย "ไม่ต้องติดตั้ง PHP หรือเปิด XAMPP ใดๆ ทั้งสิ้น" 
เพียงแค่ดับเบิ้ลคลิกเปิดผ่าน Google Chrome, Microsoft Edge หรือเบราว์เซอร์ใดก็ได้!

--------------------------------------------------------------------
📑 รายชื่อไฟล์ในโฟลเดอร์นี้ และสิ่งที่สามารถทดสอบได้:
--------------------------------------------------------------------

1. [ index.html ] - หน้าแรกของระบบ
   - สไลด์แบนเนอร์โปรโมชั่น AI (เบียร์ช้าง 199.- / แสงโสม 599.-)
   - กรอบสี่เหลี่ยมเลือกร้านผับบาร์ในเมืองสงขลา (Nockout Pub / Fullmoon Club)
   - ไฮไลท์กติกาการตัดสิทธิ์ No-Show 20:00 น.
   - เมนูทางลัดเปิดไปหน้าอื่นๆ

2. [ booking.html ] - หน้าจองโต๊ะ & ผังที่นั่งเสมือนจริง
   - ผังโต๊ะ Interactive แสดงโต๊ะว่าง (สีทอง) และโต๊ะติดจอง (สีแดง)
   - เลือกระบุเวลานัดหมายก่อน 20:00 น.
   - เลือกโปรโมชั่นเปิดโต๊ะพร้อมคำนวณยอดเงินรวมอัตโนมัติ
   - หน้าต่าง Modal สแกนชำระเงิน PromptPay QR Code + ปุ่มแนบสลิป

3. [ my-bookings.html ] - หน้าตั๋ว VIP E-Ticket
   - บัตรผ่านเข้าผับเสมือนจริง พร้อม QR Code ประจำตัว
   - นาฬิกานับถอยหลังเส้นตายตัดสิทธิ์ 20:00 น. แบบ Real-Time
   - ปุ่มแชร์ตั๋วไปยัง LINE ให้เพื่อนในกลุ่ม
   - ปุ่มขอยกเลิกการจองเพื่อคืนโต๊ะสู่ผัง

4. [ profile.html ] - หน้าโปรไฟล์ & แต้มสะสม VIP
   - บัตรสมาชิก VIP GOLD MEMBER แสดงแต้มสะสมคงเหลือ (250 แต้ม)
   - ศูนย์แลกของรางวัล VIP (ฟรีน้ำแข็ง, ฟรีมิกเซอร์, คูปองส่วนลด 100 บาท)
   - ฟอร์มแก้ไขชื่อ และเปลี่ยนรหัสผ่าน

5. [ contact.html ] - หน้าแชทสอบถาม 2 ทาง
   - ระบบจำลองการสนทนาระหว่างลูกค้ากับแอดมินร้าน
   - สามารถพิมพ์ข้อความและมีระบบจำลองแอดมินตอบกลับอัตโนมัติ

6. [ login.html ] - หน้าเข้าสู่ระบบ & สมัครสมาชิก
   - แท็บสลับระหว่าง เข้าสู่ระบบ และ สมัครสมาชิก (+50 แต้ม)
   - มีปุ่มคลิกเดียวเพื่อกรอกบัญชีทดสอบ Admin หรือ User ทันที

7. [ admin.html ] - หน้าระบบแอดมินหลังบ้าน
   - แดชบอร์ดสรุปยอดโต๊ะว่าง, โต๊ะจอง, เงินมัดจำ, No-Show
   - ระบบจัดการผังโต๊ะ: ปิดซ่อมบำรุง / สลับย้ายโต๊ะให้ลูกค้า
   - ตารางตรวจสอบสลิปโอนเงิน PromptPay
   - ปุ่มรันระบบตัดสิทธิ์โต๊ะที่เลยเวลา 20:00 น. (Manual Trigger)
